# Quantitative Backtesting Demos

This folder contains two small strategy backtesting projects:

- A stock strategy notebook that builds a rolling beta factor from high and low prices and compares configurable trading rules.
- A Bitcoin script that combines EMA trend following with Bollinger-band mean reversion, then summarizes returns, drawdown, trades, and charts.

The folder also includes exported HTML and PDF demo files.

<a id="中文"></a>
# 量化回测示例

本文件夹包含两个策略回测项目：

- 股票策略 Notebook：根据最高价和最低价构建滚动 beta 因子，并比较可调整的交易规则。
- 比特币回测脚本：结合 EMA 趋势策略与布林带均值回归策略，并展示收益、回撤、交易记录和图表。

文件夹中还包含导出的 HTML 和 PDF 示例。
